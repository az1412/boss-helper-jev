# 原版 UI 恢复与体验修复记录

## 本次结论

按用户反馈，以既有 Jev 分支的组件和样式恢复界面，不重新设计。

**日志按用户后续要求保留新版，不回退。**

目标项目：Boss Helper Jev。本次没有回退整个仓库，也没有修改筛选标准或真实账户设置。

## 恢复的外观

- 主面板恢复原桌面宽度、边距和可配置偏移，标题右侧恢复今日投递/本页处理胶囊。
- 撤下新增的大块全局运行栏；开始、继续、重置筛选、暂停及进度条回到统计页底部。
- 统计恢复原五格布局和周期下拉；错误统计含义不恢复，历史未记录的过滤比例显示“—”，不编造数据。
- 卡片恢复原版宽高、圆角、叠层和悬停动效，正文详情切换、公司信息及底部彩色状态飘带。
- 撤下新增搜索栏、六类大按钮和常驻原因区；跟随与筛选恢复左下角两个图标和动态任务节点菜单。
- 设置页只恢复实际发生变化的三处样式；没有重写原本未变的表单。
- 窄窗仅收缩主面板边界，不改正常桌面的原版尺寸；保留键盘焦点、减少动画和选择文字支持。

## 保留的体验修复

### 运行

- 执行锁从准备到结果保存完成才释放；暂停收尾期间不能重复开始。
- 原位置用按钮文字和简短状态说明等待、暂停收尾、结束或异常，不增加大面板。
- 发送确认后立即记成功；后续追加失败不覆盖已发送状态。
- 发送结果未知时停止待核实，不自动重发。
- 队列结束、最后一批与分页等待修复保留，不恢复“三批零成功即结束”。

### 卡片

- 状态分类不依赖可选任务 id；确认发送优先显示成功。
- 菜单的全选、反选、任务节点筛选仅影响视图，不改变队列或顺序。
- 滚轮只在轨道有横向余量时拦截，两端放行；手动浏览停止跟随，定位只滚轨道。
- 长详情内部纵向滚动；选中文字不误开详情。
- 完整原因通过飘带提示和按需弹窗查看，可复制，不永久占用卡片高度。

### 设置与缓存

- 取消不保存，保存失败保留草稿；求职意向单独保存，不夹带其他设置。
- 保留未保存内容的启动选择、预设切换保护以及运行快照。
- 保留 Jev 缓存按判定输入失效、同轮复用；严格度、问题、阈值、模型和排序不改。

### 日志

新版业务日志界面、成功/跳过/异常分类、本轮筛选、搜索、分页、复制与导出全部保留；默认 info、2000 条持久化及凭据脱敏也保留。

## 使用新构建

扩展目录：项目根目录下的 `.output/chrome-mv3`。

在 `chrome://extensions` 找到已加载此目录的扩展，点击重新加载，再刷新已打开的 BOSS 标签页。无需删除原扩展、清配置或重填 Key。

## 改动边界

没有删除用户文件/数据、修改密钥、数据库迁移、提交、推送或发布。

离线预览脚本支持 PORT 环境变量，并在端口被占用时自动选择可用端口；本机预览启动配置不进入源码交付。

BOSS HELPER JEV · 0.5.2.2 · CHROME 预发布版

已经编译好，按三步安装。

无需安装 Bun、Node.js 或其他开发工具。这个文件是离线安装说明，关闭后不影响扩展使用。

  1. 先把 ZIP 完整解压

    在 Windows 中右键 ZIP，选择「全部解压缩」。把解压后的文件夹放在一个固定位置，安装后保留这个文件夹。

    请从解压后的文件夹打开本说明；不要只在压缩包预览窗口里双击。该文件夹应同时包含 manifest.json 和 先打开我-安装指南.html。

  2. 在 Chrome 中加载这个文件夹

    打开 Chrome，在顶部地址栏输入下面的地址并按回车：

    chrome://extensions
    开启右上角「开发者模式」 → 点击「加载已解压的扩展程序」

    选择包含本说明和 manifest.json 的文件夹，点击「选择文件夹」。选择的是文件夹，不是 ZIP 或某一个文件。

  3. 打开 BOSS 页面，开始配置

    登录 BOSS 直聘，打开岗位搜索或推荐页面；已经打开的页面请刷新。按照扩展中的配置入口保存求职意向、筛选条件和消息内容。

    基础条件筛选 + 平台默认招呼无需 AI Key。使用 Jev 语义筛选时填写 TypeSafe Key；其他 AI 招呼或筛选使用对应模型服务的 Key。

    第一次建议设置本轮目标 1–3 个岗位，核对消息后再点开始；点击开始会执行真实沟通。

没看到扩展，或提示找不到 manifest？

确认已完整解压，且选中的文件夹直接包含 manifest.json。如果解压产生了两层同名文件夹，请进入内层再选择。更新已有安装时沿用原文件夹，在扩展页面点「重新加载」，然后刷新 BOSS 页面。

本版当前验证目标为 Chrome。启用 AI 会将相关岗位和填写的求职资料发送给所配置服务商，可能产生 API 费用；详细说明见同目录 PRIVACY.md。安装包不包含账号、Key 或个人配置，需要本人填写。使用说明可在 GitHub 仓库 az1412/boss-helper-jev 的 docs 中查看。

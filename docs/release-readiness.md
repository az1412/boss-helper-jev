## AI 配置检查结果

| 问题 | 本版处理 |
| --- | --- |
| 编辑后取消影响原配置 | 编辑器、模型列表草稿、已保存配置分离；失败保留草稿 |
| 改配置后仍沿用旧模型或旧密钥 | 实际请求读取已保存的配置快照，不保留旧 provider 缓存 |
| 测试与真实调用参数不同 | 共用请求实现，统一 Responses、流式、JSON、采样、超时和额外参数 |
| 供应商切换残留旧密钥 | 切到预设或自定义供应商都会清空旧密钥 |
| 地址、JSON 或模型引用无效 | 保存前校验；被当前配置选用的模型不能直接删除 |
| 重复测试或失败请求扩大消耗 | 测试连接仅主动发送一次请求；禁用 SDK 自动重试；错误提示不附带请求正文 |
| 配置入口分散、参数难懂 | AI 页分成筛选方式、招呼方式、模型服务；高级参数折叠；移除独立对话 |
